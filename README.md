# 🚀 LeetCode Analytics Dashboard

A modern LeetCode analytics dashboard built using Vanilla JavaScript, Async/Await, Fetch API, and dynamic DOM rendering.

## ✨ Features

* Live LeetCode data fetching
* Dynamic circular progress UI
* Real-time solved problem analytics
* Async/Await architecture
* Error handling & validation
* Responsive glassmorphism design
* Dynamic CSS variable updates

## 🧠 Concepts Practiced

* Promises & Async JavaScript
* API Integration
* DOM Manipulation
* Dynamic UI Rendering
* Error Handling
* Frontend Architecture

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Fetch API

Built mainly to deeply understand asynchronous programming and real-world frontend data flow.
